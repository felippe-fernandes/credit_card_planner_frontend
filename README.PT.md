## 📖 Sobre

Esta é a aplicação do lado do cliente para o sistema Credit Card Planner, fornecendo uma interface amigável para gerenciar múltiplos cartões de crédito, rastrear faturas mensais e visualizar gastos financeiros.

## ✨ Funcionalidades

- **🔐 Autenticação Segura**: Login e cadastro com autenticação baseada em JWT via Supabase.
- **💳 Gestão de Cartões**: Adicionar, editar e gerenciar múltiplos cartões de crédito.
- **📊 Rastreamento de Transações**: Registrar e categorizar todas as suas transações de cartão de crédito.
- **🧾 Gestão de Faturas**: Rastrear faturas mensais para cada cartão de crédito.
- **📂 Organização por Categoria**: Organizar transações por categorias personalizadas.
- **👥 Suporte a Dependentes**: Gerenciar despesas para membros da família ou dependentes.
- **📱 Design Responsivo**: Interface totalmente responsiva que funciona em desktop, tablet e celular.
- **🌓 Modo Escuro**: Suporte integrado a modo escuro para visualização confortável.
